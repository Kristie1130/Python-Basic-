## Day 1: Python Variables

Today I learned about **variables in Python**.

### What is a variable?
A variable is used to store data in a program.

### Rules for naming variables
- A variable name must start with a letter or underscore (_)
- It cannot start with a number
- No spaces are allowed
- It should not be a Python keyword
- Use meaningful names

### Examples

```python
name = "Christiana"
age = 22
school = "University"

print(name)
print(age)
